# 博客与内容源列表

本文收集 LLM 学习相关的博客、官方技术内容源与深度研究站点，覆盖个人博客、机构官方博客、中文社区资源与可解释性前沿研究。

## §1 牛人博客

个人技术博客，作者多为 AI 领域知名研究者或从业者，以深度原创内容见长。

- [Lil'Log](https://lilianweng.github.io/): Lilian Weng（翁丽莲）的个人博客。她是人工智能领域知名研究者，曾任 OpenAI 安全研究负责人。博客以深入浅出地讲解复杂的机器学习、深度学习与 AI 安全概念而闻名，是 AI 从业者与爱好者学习的重要资源。

## §2 官方博客与工程实践

机构官方技术博客与文档，聚焦模型、工具与工程落地，更新频繁、内容权威。

- [Hugging Face Blog](https://huggingface.co/blog): Hugging Face 官方博客，覆盖 Transformers / Diffusers / PEFT 等库的发布说明、模型介绍、训练与推理教程，以及开源社区动态，是追踪开源模型生态的一手来源。
- [NVIDIA Technical Blog](https://developer.nvidia.com/blog/): NVIDIA 官方技术博客，覆盖 Agentic AI、模型训练与微调、推理优化（TensorRT、量化）、MoE 预训练、合成数据等主题，从底层硬件（Blackwell/Vera Rubin）到上层应用（编码代理、机器人）的全栈技术内容，更新频率极高。
- [Anthropic Newsroom](https://www.anthropic.com/news): Anthropic 官方新闻中心，发布 Claude 系列模型（Opus/Sonnet/Haiku 等）的产品更新、技术公告、安全与对齐工作进展，以及公司政策立场声明，是了解 Anthropic 动态的权威渠道。
- [Anyscale LLM Docs](https://docs.anyscale.com/llm): Anyscale 官方 LLM 与 Agentic AI 文档，基于 Ray 分布式框架，覆盖 LLM 服务（Ray Serve + vLLM）、后训练与 Agentic tuning（SFT/RLHF/DPO/GRPO/RLVR）、批量推理、RAG 流水线、Agent 与 MCP 部署等端到端工程实践。

## §3 中文社区资源

中文 AI 学习社区与知识库，面向中文开发者与学习者。

- [WaytoAGI 知识库](https://waytoagi.feishu.cn/wiki/QPe5w5g7UisbEkkow8XcDmOpn8e): WaytoAGI 的中文 AI 学习知识库（飞书 wiki），聚合大量 AI 学习路径、工具与资源导航，是中文 AI 社区的重要入口。

## §4 深度研究站点

聚焦机制可解释性与前沿研究的专题站点，内容偏学术与深度。

- [Transformer Circuits Thread](https://transformer-circuits.pub/): Anthropic 可解释性研究团队（Interpretability Team）的独立发布站点，专注机制可解释性（mechanistic interpretability），发布稀疏自编码器（SAE）、特征提取、circuit tracing 等前沿研究，是理解大模型内部机制的权威来源。
