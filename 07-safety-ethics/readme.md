## 10. 学术论文与研究跟踪（Papers & Research Tracking）

- [arXiv: LLM 对齐与安全日报](https://www.arxivdaily.com/topics/llm-alignment-safety)：每日自动更新的 LLM 对齐与安全论文追踪页，按主题分类抓取 arXiv 新提交，帮助研究者省时掌握领域最新文献。
- [A Survey on LLM based Autonomous Agents（arXiv 2310.19852）](https://arxiv.org/abs/2310.19852)：基于大语言模型的自主智能体（Agent）领域权威综述，系统梳理 Agent 构建、规划、记忆与评估模块，含安全可信专题，引用量极高。

- <img src="https://img.shields.io/github/stars/tjunlp-lab/Awesome-LLM-Safety-Papers?style=social" height="17" align="texttop"/> [Awesome-LLM-Safety-Papers](https://github.com/tjunlp-lab/Awesome-LLM-Safety-Papers): 吉林大学 TJUNLP 实验室维护的 LLM 安全论文集，按研究主题分类收录安全评测、攻击与防御文献，更新频繁且分类体系清晰。
